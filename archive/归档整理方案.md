````
## ⚠️ 风险与注意事项

### 1. 导入路径变更

Pipeline 文件重组后，所有引用这些文件的代码需要更新导入路径：

**变更前**:

```python
from src.pipeline.compose_spectrum import ...
````

**变更后**:

```python
from src.pipeline.compose.compose_spectrum import ...
```

**影响范围**:

- 根目录 CLI 脚本（spectrum_cli.py, spectrum_batch.py）
- 测试文件
- 演示脚本
- README 等文档中的代码示例

### 2. 向后兼容性

建议在旧位置保留兼容性导入（临时方案）：

```python
# src/pipeline/compose_spectrum.py (临时文件)
from src.pipeline.compose.compose_spectrum import *
import warnings
warnings.warn("请使用 src.pipeline.compose.compose_spectrum", DeprecationWarning)
```

````

### 3. 文档同步

需要更新的文档：

- README.md - 目录结构说明
- USAGE_CLI.md - 示例代码
- USAGE_GUIDE.md - 导入路径
- docs/ 下的所有技术文档
````
