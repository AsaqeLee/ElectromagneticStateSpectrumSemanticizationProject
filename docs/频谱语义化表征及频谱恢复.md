# 频谱语义化表征及频谱恢复

由于信道受到干扰时，信道容量下降，进行电磁环境进行语义化描述的目的是为了降低信息共享信道信息的业务量，使用较少的带宽在接收端可以恢复出信道环境。

在对电磁环境的语义化表征中，需要表征的参数主要有当前信道是否存在干扰、干扰信号的起始频率、截止频率、信噪比等信息，采用结构化的表征方式，设计如下图所示的电磁环境语义基。

感知结果恢复方法：

1、本地节点收到远端节点发来语义化表征后的频谱参数，参数包括节点编号、干扰的起始频率、干扰的截止频率、每个干扰的能量大小、干扰带宽以及底噪大小（如表1所示）；  
2、构建与感知范围等长的数组，其值为底噪大小，步长为感知分辨率大小；  
3、在干扰带宽范围内根据干扰功率与感知分辨率计算每根谱线的能量大小；即在有干扰的位置，谱线能量大小为干扰能量大小，其他无干扰位置谱线能量大小为底噪能量；  
4、根据干扰起始频率、截止频率进行计算，计算每个干扰的带宽范围内有多少根谱线，在本地恢复出远端节点位置的频谱参数；如下图所示，可以将语义化表征的参数恢复为频谱图。和原始信道环境经过处理后的频谱相比，两者误差最大不超过感知分辨率。
